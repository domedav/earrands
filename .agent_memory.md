## New App Spec: Ballanceometer com.domedav.ballanceometer
- Purpose: unlock money by doing tasks. 2 pages: Config + Show (+ widget)
- Config: totalBalance (Double), minimalSpend (Double), TaskGroups (name, weight 0-100 slider), Subtasks (title, recurrence: ONCE/DAILY/WEEKLY/MONTHLY, optional one-time)
- Math: earnable = max(0, total - minimal). weightSum>0 ? groupShare = earnable * (group.weight / weightSum). Each subtask instance value = groupShare / totalInstancesInMonth (instances computed from recurrence). Today unlocked = sum(completed instances today value). Available = minimal + unlocked - spent? Or show available balance = unlocked + minimal - totalSpent.
- Show: Balance meter (circular/Linear), available, unlocked, spent, today's todos checklist, subtract spend dialog
- Widget: same balance + today todos + spend shortcut?
- Storage: Room v2, entities: AppConfig, TaskGroup, Subtask, Completion, Spending
